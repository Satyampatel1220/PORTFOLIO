# Satyam Patel — Portfolio

A responsive portfolio website built with HTML, CSS, and JavaScript.

## Run locally
1. Download and unzip this folder.
2. Open `index.html` in your browser, or open the folder in VS Code.
3. Optional: use the Live Server extension in VS Code.

## Before publishing
- Check that the AppDost repository URL and technology tags are correct.
- Replace the “Live Demo soon” links with actual deployed URLs when available.
- Replace the LinkedIn link with your real profile URL.
- Only list technologies and features that you can confidently explain in an interview.

## Publish using GitHub Pages
1. Create a new public repository named `Satyampatel1220.github.io` (GitHub usernames are case-sensitive; use your exact username).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for deployment and open `https://satyampatel1220.github.io/`.

GitHub Pages can host this static portfolio for free. If the repository name or username differs, the URL will differ too.
